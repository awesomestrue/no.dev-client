# no.dev client

Десктопное приложение для Windows, которое объединяет в одном окне
управление двумя инструментами обхода блокировок:

- **Zapret** (`winws.exe`) — для YouTube и Discord.
- **tg-ws-proxy** — для Telegram.

Вместо двух отдельных приложений с двумя треями — один GUI, одна тема,
один лог.

---

## ✨ Возможности

- **Единое окно** для Zapret и Telegram.
- **Три темы оформления**: Светлая, Тёмная, Стеклянная (сохраняется).
- **Профили Zapret** — автопоиск `.bat`-файлов в папке Zapret.
- **Сохранение последнего профиля** — при следующем запуске выбран
  автоматически.
- **Автозапуск Telegram** вместе с Zapret (один чекбокс).
- **Автозапуск при старте системы** с правами администратора
  (через Планировщик заданий).
- **Интерактивный `service.bat`** — установка/удаление службы, обновление
  IPsets и hosts, диагностика, тесты. Всё из GUI, без отдельных окон
  консоли.
- **Результаты тестов** — просмотр файлов `test_results_*.txt` прямо в логе.
- **Очистка кэша Discord** — одной кнопкой.
- **Секция Hosts** — быстрое добавление записей (например, для иконок
  Roblox: `18.65.39.105 tr.rbxcdn.com`).
- **Индикатор прав администратора** прямо в главном окне.

---

## 📋 Требования

- **Windows 10 или Windows 11** (64-bit).
- **Python 3.13 или новее**.
- **Права администратора** для работы `winws.exe` (WinDivert).
